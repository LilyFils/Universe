# Polina's Universe ✨

Интерактивный веб-проект, разработанный в качестве персонального поздравления с днём рождения.

Проект представляет собой небольшое веб-приложение с анимированным звёздным небом, интерактивными элементами и последовательным переходом между сценами 🌍

Реализован на HTML, CSS и JavaScript без использования сторонних фреймворков.

## Функциональность

Приложение состоит из трех основных сцен:

**1. Главная сцена**
- Иллюстрация с анимированным звездным небом.
- Мерцание звёзд и анимация падающих метеоров.
- Интерактивные области изображения.
- Плавный переход к следующей сцене.

**2. Информационная сцена**
- Сообщение с описанием интерактивного задания.
- Анимированный фон.
- Кнопка перехода к звездной карте.

**3. Интерактивное созвездие**
- Звездная карта с интерактивными точками.
- Постепенное построение букв имени POLINA с помощью SVG.
- Анимация соединительных линий и свечения звезд.
- Отслеживание прогресса.
- Модальное окно с поздравлением после завершения задания.

## Технологии

- **HTML5** — структура страниц и элементов интерфейса.
- **CSS3** — стилизация, адаптивная вёрстка и анимации.
- **JavaScript (Vanilla JS)** — логика взаимодействия и управление сценами.
- **SVG** — отрисовка интерактивного созвездия.

## Адаптивность

Интерфейс адаптирован для настольных компьютеров и мобильных устройств.

Реализованы:
- Адаптивное масштабирование иллюстраций и элементов интерфейса.
- Поддержка экранов шириной от 320 px.
- Увеличенные области нажатия для сенсорных устройств.
- Адаптация SVG-созвездия под мобильные экраны.
- Учёт безопасных областей экрана (safe-area).
- Прокрутка модального окна на экранах небольшой высоты.

Верстка проверялась при ширине экрана 320, 375, 390 и 430 px. Тестирование на физическом устройстве с iOS пока не проводилось.
